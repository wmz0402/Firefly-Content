大家好啊，这是我在这个博客里所写的第一篇文章，总感觉无从下笔，但又觉得这样下去也不行，总要有一个开头来破冰，所以就写下了这篇文章。没有很多有用的知识，就是用来闲聊的。

## 梦开始的地方

我为什么给这篇文章起这个标题呢？因为作为程序员，我们在学习任意一门编程语言的时候，所敲的第一行代码就是打印：

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

怎么说，算得上是梦开始的地方吧。

我记得我第一次接触编程的时候是在高考后的那个暑假，当时收到录取通知书看到这个专业的时候还挺惊讶的，根本没有想到会被这个专业所录取。当时不是很想读这个专业，因为我是一个计算机小白，几乎没有碰过电脑，对计算机更是提不起一点兴趣。但是我的心态还是很好的，既来之则安之嘛。刚好那个时间段我们学校开设的有前置教育课程，于是就开启了我的计算机之旅。

C 语言可以说是所有编程语言的祖先，所以最开始我们学习的也是 C。还记得当时第一次敲出这个代码的时候超级惊喜，感觉好神奇呀！正是有了这一契机把我带进了编程的世界。随着之后的学习，发现计算机其实还挺有意思的，没有我想的那么枯燥，反而充满了新鲜感。

我想也许是之前从未接触过的原因，让我对他的热情持续了好久，一整个学期都在不断汲取知识中度过。你要问我累吗？当然，非常累。可能是因为大学刚开学对未来充满了无限的希望，充满了无限的干劲，所以一有时间就去参加讲座，参加社团培训。我记得当时军训的时候，几乎没有一次中午是在宿舍里度过的，都在参加社团组织的培训。但是过的很充实，只能说是痛并快乐着吧。

---

## 奇遇与陪伴：宿舍里的美好回忆

其实感觉挺庆幸的，在大学里面遇到了一群相处融洽的室友。在网上看的猎奇的宿舍多了，所以感觉遇到他们挺幸运的。

我们一起诉说自己曾经的经历，就像是打开了一本名为“奇遇”的书，去感受那些我们所没有经历过的事物；再到后来我们慢慢熟络之后，一起探索学校周边的美食，一起去学习，一起去探索这个城市，一起去拓宽我们的眼界，丰富我们的阅历。

虽然在这一路途中，我们会有小摩擦，会有争执，但最终又能重归于好。我始终认为：

> **人和人之间没有完全的契合，有的只是在相处的过程中互相的磨合、包容和改善。**

毕竟人无完人，没有任何人是完美的，多多少少都会有自己的缺点。所以在经历过这么多，各种缺点都暴露出来之后，我们还能一起去探索、去游玩，是一件很幸运的事。虽然说我们以后可能会分道扬镳，会各自回到各自的城市，可能以后也不会经常联系，但我想每当回望这段大学生活的时候，我们都是不可磨灭的存在，这段美好的回忆会一直被珍藏。

---

## 遇到闪闪发光的他们：社团的挚友

还有令我记忆深刻的就是我在社团里面遇到的朋友吧。

### 黎明学长：移动的百科全书
其实我最感谢的就是我的学长**黎明**，同时也是我的好朋友。我感觉他教会我很多东西，就像是一本“百科全书”，问啥他都会。我感觉我能有现在的这个知识储备和能力，有他一半的功劳，在有些时候确实也开导我很多。

他属于那种很无私的学长，不仅仅是在我需要他提供帮助的时候指导我、帮助我，还会主动让我们了解更多前沿的东西，学习到很多在学校教室里学不到的内容。而且很多时候，他不仅仅是提供问题的答案，而是教给我们解决问题的方法。他的这种好不知说是对我们这些和他玩得比较好的，而是对我们社团里的每位同学。所以说真的挺幸运遇到他的。

### 李婷婷：坚韧温和的精神支柱
还有一个我社团的好朋友就是**李婷婷**，她是那种看起来文文静静，但是有着很强精神内核的小女生。我也挺庆幸遇到她的，成为了我的学习搭子。

其实我是一个精神内核非常弱的人吧，感觉小小的事也能影响我的心情，也会困扰我好久。但是每当遇到这种情况的时候，她总是会过来开导我，真的挺感谢她的，教会我挺多应对的方法、思考的方式与处理的态度。

觉得他们很好，也并不是主观臆断只是对我一个人好，而是他们本身就是很好的人，只是很庆幸被我遇到了。
